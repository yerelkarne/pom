# Pomodoro

Pomodoro, Jetpack Compose + Material3 ile geliştirilmiş, üretime yakın kaliteye sahip bir Pomodoro odaklanma uygulamasıdır.

## Gereksinimler
- Android Studio Hedgehog veya üstü
- JDK 17
- Android SDK (API 35)

## Kurulum
1. Depoyu Android Studio ile açın.
2. Gradle senkronizasyonunu tamamlayın.
3. Bir cihaz veya emülatör seçip **Run** butonuna tıklayın.

## Test Reklam Kimlikleri
Bu projede Google test reklam kimlikleri kullanılmıştır. Prod ortamına geçerken `AdConstants` içindeki ID'leri güncelleyin.

## Notlar
- Bildirim izni Android 13+ için runtime olarak istenir.
- Arka plan görselini değiştirmek için `app/src/main/res/drawable/bg_pomodoro_placeholder.txt` dosyasını silip yerine `bg_pomodoro.jpg` ekleyin.

Daha fazla bilgi için `USAGE_GUIDE.md` dosyasına bakın.
